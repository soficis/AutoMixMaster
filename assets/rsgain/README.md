# rsgain renderer bundle

Place the rsgain executable in `assets/rsgain/bin/`.

- Windows: `assets/rsgain/bin/rsgain.exe`
- Linux/macOS: `assets/rsgain/bin/rsgain`

You can also override discovery with `RSGAIN_BIN=<absolute path to rsgain binary>`.

The `rsgain` renderer runs a ReplayGain tagging pass after render completion.
